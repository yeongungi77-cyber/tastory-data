TASTORY 홈 데이터 (Data/Home) — v1.320, 로드맵 26·27

홈의 '이달의 일본 미식'(monthly.json)과 TASTORY PICK(picks.json). 프로그램을 빌드할 때 함께 들어간다(고친 뒤 다시 빌드).
서버가 시작할 때 검사해 잘못된 항목만 빼고 /api/home 으로 넘긴다(home.go). 무엇이 빠졌는지: 개발판 화면 콘솔의
'홈 데이터 검사' 경고, 또는 go test ./... (home_test.go TestHomeClean 이 경고 0개를 요구한다).

[카드 하나]  ★ = 필수
  name★    화면 이름(한국어 20자 이내)
  ja       일본어 이름(30자 이내, 한국어 금지)
  search★  '○○에서 찾기'를 누르면 Google 지도에서 찾을 말(40자 이내, 일본어 권장 — 'ふぐ料理', '海鮮丼 朝')
  desc★    설명(120자 이내). 홈 카드에는 3줄까지, 누르면 전부
  cities   찾아볼 도시(Data/City 의 준비된 도시 이름만 — 준비 중·없는 도시는 빼고 경고)
           monthly.json 은 하나 이상 필수, picks.json 은 비우면 지금 여행 도시에서 찾는다

[monthly.json]
  schema★ 1
  months★ {"1": [카드…], …, "12": [카드…]}  — 달마다 4~5개 권장(8개까지). 화면은 오늘 날짜의 달을 보여 준다

[picks.json]
  schema★ 1
  picks★  [{"id": 영문 소문자(중복 금지), "icon": 이모지, "title"★: 20자 이내, "desc": 80자 이내, "items"★: [카드…](8개까지)}]
          화면 순서 그대로. 12개까지

[찾기 동작] (app_home.js homeFindFood)
  지금 여행 도시면 바로 검색 · 음식점이 없으면 도시만 바꾸고 검색 ·
  음식점이 있으면 지역 선택과 같은 흐름(확인 → 지금 여행을 계획표로 저장 → 새 여행)으로 바꾼 뒤 검색
